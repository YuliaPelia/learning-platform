## Наскрізні сценарії для `qa-browser`

Демо-акаунти — у README.md. Оплата лише через «Імітувати успішну оплату».

- **S-1 Батьки:** реєстрація → додати дитину → тарифи → оплата (імітація) → підписка «Активна» в кабінеті → скасування.
- **S-2 Дитина:** вхід `maks` → відкрити безкоштовний урок → пройти тест → здати домашку → XP/рівень у кабінеті.
- **S-3 Доступ:** без підписки платний урок закритий, 2 безкоштовні відкриті; чужий кабінет недоступний.
- **S-4 Викладач:** вхід teacher → черга «submitted» → оцінка + коментар → повторно оцінити не можна.
- **S-5 Повідомлення:** батько пише викладачу → викладач відповідає → обидва бачать тред.
- **S-6 Безпека входу:** кілька невдалих входів → блокування (A-1).
- **S-7 Адмін:** створити курс і урок, перевірити, що він видно в каталозі.
